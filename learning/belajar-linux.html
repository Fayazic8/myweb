Apa itu Linux & Kenapa Harus Dipelajari?

Linux adalah sistem operasi open-source yang berjalan di sebagian besar server dunia, termasuk server Google, Facebook, dan hampir semua cloud provider. Kalau lo serius di bidang IT, sysadmin, atau bahkan trading berbasis bot — lo pasti butuh Linux.

CLI (Command Line Interface) bukan sekadar "cara kuno" — ini adalah cara yang paling efisien, cepat, dan powerful untuk mengontrol sebuah sistem. Satu baris perintah bisa menggantikan 10 langkah klik di GUI.

🐧

Kernel

Inti dari Linux. Jembatan antara software dan hardware. Lo tidak berinteraksi langsung, tapi semua perintah bermuara ke sini.

🖥️

Shell

Program yang membaca perintah lo dan meneruskannya ke kernel. Contoh: bash, zsh, sh. Yang paling umum adalah bash.

📁

Filesystem

Struktur direktori Linux dimulai dari / (root). Bukan C:\ kayak Windows. Semua dalam satu pohon.

👤

User & Root

Ada user biasa dan root (superuser). Root punya akses penuh — berbahaya kalau salah dipakai. Gunakan dengan sadar.

📦

Distro

Versi Linux yang dibungkus berbeda. Ubuntu (pemula), Debian (server), Arch (advanced). Pelajari Ubuntu/Debian dulu.

⚙️

Package Manager

Tool untuk install/hapus program. Di Ubuntu/Debian pakai apt. Di RedHat/CentOS pakai yum atau dnf.

💡
Cara Praktik Tanpa Install Linux:

Pakai WSL (Windows Subsystem for Linux) di Windows 10/11, atau coba langsung di browser via webminal.org atau linuxzoo.net. Tidak ada alasan untuk tidak mulai hari ini.

Navigasi Sistem File

Di Linux, semua dimulai dari / (root directory). Bayangkan ini sebagai C:\ tapi versi Linux. Dari sini semua direktori tumbuh ke bawah seperti pohon.

Ada dua jenis path: Absolute (dimulai dari /, contoh: /home/fayazi/dokumen) dan Relative (relatif dari posisi sekarang, contoh: ../dokumen). Pahami ini dulu sebelum lanjut.

📂
Struktur Direktori Penting di Linux:

/home — folder user (kayak Documents di Windows) | /etc — semua file konfigurasi | /var — log dan data variabel | /tmp — file sementara, dihapus saat reboot | /bin & /usr/bin — program-program yang bisa dijalankan

03

Operasi File & Direktori

Ini adalah operasi yang paling sering lo pakai: buat, salin, pindah, hapus, dan baca file. Hafalkan ini sampai jadi otomatis di jari lo.

Perhatian: Di Linux tidak ada "Recycle Bin" di terminal. Perintah rm langsung hapus permanen. Tidak bisa di-undo.

bash — operasi file
Buat direktori baru
mkdir proyek-trading
Buat direktori beserta sub-direktorinya sekaligus (-p)
mkdir -p proyek-trading/data/csv
Buat file kosong (atau update timestamp jika sudah ada)
touch catatan.txt
Tulis teks ke file (hati-hati: > akan TIMPA isi file)
echo "Ini catatan pertama saya" > catatan.txt
>> untuk TAMBAHKAN ke file (tidak menimpa)
echo "Entry baru ditambahkan" >> catatan.txt
Baca isi file
cat catatan.txt
Ini catatan pertama saya
Entry baru ditambahkan
Salin file
cp catatan.txt catatan-backup.txt
Salin direktori beserta seluruh isinya (-r)
cp -r proyek-trading proyek-trading-backup
Pindahkan file (atau rename jika di direktori sama)
mv catatan.txt proyek-trading/catatan.txt
Rename file
mv nama-lama.txt nama-baru.txt
HAPUS file — PERMANEN, tidak bisa undo!
rm catatan-backup.txt
Hapus direktori kosong
rmdir direktori-kosong
Hapus direktori + semua isinya (-rf = recursive + force)
rm -rf proyek-trading-backup
⚠️
JANGAN PERNAH jalankan ini:

rm -rf / atau rm -rf /* — ini akan menghapus SELURUH sistem lo. Tidak ada recovery. Ini bukan mitos. Beberapa orang sudah merusak server production mereka karena ini.

⚡
Wildcard — Hemat Ketikan:

* = semua karakter. Contoh: rm *.log hapus semua file .log | ls *.txt tampilkan semua file txt | cp data*.csv /backup/ salin semua file csv yang dimulai dengan "data"

04

Permission & Kepemilikan File

Ini adalah salah satu konsep paling penting di Linux. Setiap file punya tiga level permission: untuk owner (pemilik), untuk group, dan untuk others (semua orang lain). Dan tiga jenis aksi: r (read/baca), w (write/tulis), x (execute/jalankan).

Kalau lo pernah lihat permission denied saat menjalankan sesuatu, ini penyebabnya.

bash — memahami permission
Lihat permission file
ls -la
-rwxr-xr-- 1 fayazi fayazi 1024 Jul 10 catatan.txt
Breakdown: -rwxr-xr--
- → tipe file (- = file biasa, d = direktori, l = symlink)
rwx → owner (fayazi): bisa baca, tulis, dan jalankan
r-x → group: bisa baca dan jalankan, TIDAK bisa tulis
r-- → others: hanya bisa baca
Ubah permission dengan chmod (mode numerik)
4=read, 2=write, 1=execute. Dijumlahkan: 7=rwx, 6=rw-, 5=r-x, 4=r--
chmod 755 script.sh
755 = owner(7=rwx) group(5=r-x) others(5=r-x)
chmod dengan mode simbolik (lebih mudah dibaca)
chmod +x script.sh
+x = tambahkan execute permission untuk semua
chmod u+w,g-w catatan.txt
u=user/owner, g=group, o=others, a=all
Ubah kepemilikan file
chown fayazi:fayazi file.txt
Jalankan perintah sebagai root (superuser)
sudo apt update
[sudo] password for fayazi:
Hit:1 http://archive.ubuntu.com focal InRelease
Reading package lists... Done
🔑
Hafalan Cepat Permission Angka:

777 = semua orang bisa apa saja (berbahaya di server!) | 755 = standar untuk executable/folder | 644 = standar untuk file biasa | 600 = hanya owner yang bisa baca+tulis (cocok untuk SSH key)

UJI PEMAHAMAN

1. Perintah apa yang digunakan untuk membuat file bernama script.sh bisa dieksekusi oleh semua user?

✓ Benar! chmod +x menambahkan execute permission untuk semua (owner, group, others). Alternatifnya bisa juga chmod 755 untuk lebih spesifik.

2. Lo lihat permission rw-r--r-- pada sebuah file. Apa artinya?

✓ Benar! rw- = read+write (no execute) untuk owner. r-- = read only untuk group. r-- = read only untuk others. Ini setara dengan chmod 644.

Proses & Monitoring Sistem

Setiap program yang berjalan di Linux adalah sebuah proses dengan ID unik (PID). Lo perlu tahu cara melihat proses yang berjalan, menutupnya, dan memantau kesehatan sistem — terutama kalau lo manage server atau bot trading.

bash — monitoring proses & sistem
Lihat semua proses yang berjalan (snapshot)
ps aux
USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
root 1 0.0 0.1 168576 11120 ? Ss 09:00 0:01 /sbin/init
fayazi 1234 2.5 1.2 650000 48000 pts/0 Sl 09:15 0:10 python3 bot.py
Tampilan real-time (kayak Task Manager). Tekan Q untuk keluar
top
htop — versi top yang lebih cantik (perlu install dulu)
sudo apt install htop -y && htop
Cari proses berdasarkan nama
pgrep python3
1234
Matikan proses berdasarkan PID (SIGTERM = minta berhenti dengan sopan)
kill 1234
Paksa matikan (SIGKILL = langsung bunuh, jika kill biasa tidak mempan)
kill -9 1234
Matikan semua proses bernama python3
pkill python3
Cek penggunaan disk
df -h
Filesystem Size Used Avail Use% Mounted on
/dev/sda1 20G 12G 6.8G 64% /
Cek ukuran direktori/file (du = disk usage)
du -sh /home/fayazi/
2.1G /home/fayazi/
Cek RAM yang terpakai
free -h
total used free shared buff/cache available
Mem: 7.8G 2.1G 4.2G 200M 1.5G 5.2G
Jalankan proses di background (tambah & di akhir)
python3 bot.py &
[1] 1567
Sekarang terminal bebas dipakai lagi, bot jalan di background
🤖
Relevansi ke Trading Bot:

Kalau lo nanti punya bot trading yang jalan di VPS, lo harus bisa: cek apakah bot-nya masih jalan (ps aux | grep bot), restart kalau crash (kill PID lalu jalankan lagi), dan monitor RAM/CPU supaya server tidak kehabisan resource.

06

Manipulasi Teks & Pipe

Di Linux, hampir semua konfigurasi dan output adalah teks. Kemampuan membaca, mencari, dan memfilter teks adalah skill wajib. Pipe (|) adalah konsep terpenting di sini — output dari perintah pertama dijadikan input perintah kedua.

bash — teks dan pipe
cat — tampilkan seluruh isi file
cat /var/log/syslog
less — tampilkan file satu layar penuh (Q untuk keluar, Space untuk next)
less /var/log/syslog
head — tampilkan 10 baris pertama
head -20 /var/log/syslog
tail — tampilkan 10 baris terakhir (-f untuk live/follow)
tail -f /var/log/syslog
Cocok banget untuk monitoring log bot trading secara live!
grep — cari baris yang mengandung kata tertentu
grep "error" /var/log/syslog
Jul 10 09:15:02 myserver error: connection timeout
Jul 10 09:18:44 myserver error: disk full
grep -i = case insensitive, -r = recursive (cari dalam folder)
grep -ri "password" /etc/
PIPE (|) — output dari ps aux masuk ke grep
ps aux | grep python
fayazi 1234 2.5 1.2 ... python3 bot.py
Hitung jumlah baris di file (wc -l)
wc -l data-trading.csv
1500 data-trading.csv
Contoh pipe berantai: cari error, ambil 5 terakhir, hitung
grep "error" /var/log/syslog | tail -5 | wc -l
5
sort — urutkan baris (sort -r untuk descending)
cat nilai.txt | sort
uniq — hapus baris duplikat (harus disort dulu)
cat list.txt | sort | uniq

Perintah Jaringan Dasar

Untuk sysadmin atau developer yang kerja dengan server, mengerti perintah jaringan dasar itu wajib. Mulai dari cek koneksi, download file, sampai akses server remote via SSH.

Download file dari internet
wget https://example.com/data.csv
curl -O https://example.com/data.json
SSH — masuk ke server remote (VPS lo)

fayazi@123.456.789.0's password:
Welcome to Ubuntu 22.04 LTS
Last login: Wed Jul 10 08:00:00 2025 from 192.168.1.1
SSH dengan port custom dan key file
